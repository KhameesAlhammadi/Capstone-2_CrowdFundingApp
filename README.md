# 🏗️ WeFundEachOther

A cross-platform **crowdfunding investment application** that enables users to invest in real estate opportunities with low budgets and track their investments in a simple and secure way.

---

## 📌 Overview

WeFundEachOther is designed to make property investment more accessible for new investors by allowing them to contribute smaller amounts into larger real estate projects. The application provides a clean user experience with secure authentication, investment tracking, and real-time data updates.

---

## 🚀 Features

- 🔐 Secure user authentication (Firebase)
- 📊 User dashboard to track investments
- 🏠 Property listing and investment system
- 💰 Low-budget investment participation
- 🔄 Real-time data updates
- 📱 Cross-platform (Android & iOS)
